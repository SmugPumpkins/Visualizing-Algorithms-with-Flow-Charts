# Visualizing Algorithms with Flow Charts

Create three flowcharts that visually represent simple mathematical algorithms. Each challenge is designed to practice one of the control structures from this lesson: **sequence, selection, and iteration**.

Use a flowcharting program such as [diagrams.net](https://app.diagrams.net/). Your flowcharts should use the correct Start/End, Input/Output, Process, and Decision symbols where appropriate, with arrows showing the order in which the algorithm runs.

## Requirements

* [ ] Create a flowchart for **Challenge 1 — Rectangle Calculator**. Ask for a rectangle's `length` and `width`, calculate its area using `length × width`, and output the area. Save the exported image as `challenge_1_rectangle.png`.
* [ ] Create a flowchart for **Challenge 2 — Larger Number**. Ask the user for two numbers, compare them using a decision, and output which number is larger. Save the exported image as `challenge_2_larger_number.png`.
* [ ] Create a flowchart for **Challenge 3 — Running Total**. Start a total at `0`, repeatedly add the numbers `1` through `5` to the total, and output the final total when the repetition is finished. Save the exported image as `challenge_3_running_total.png`.
* [ ] Each flowchart must include a **Start** and **End** symbol.
* [ ] Use **Input/Output symbols** whenever information is entered or displayed, **Process symbols** for calculations or variable changes, and **Decision symbols** when the algorithm must choose or repeat.
* [ ] Connect all symbols with arrows so there is a clear path showing the order in which the algorithm runs.
* [ ] Each flowchart should use short, clear descriptions inside its symbols rather than Python code.
* [ ] Export all three flowcharts as image files and place them inside the repository's `submissions` folder using the exact filenames listed above.

Your submitted repository should contain:

```text
submissions/
├── challenge_1_rectangle.png
├── challenge_2_larger_number.png
└── challenge_3_running_total.png
```
